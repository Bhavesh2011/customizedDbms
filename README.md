# Customized DBMS – Employee Record Management System

**Author:** Bhavesh Narayan Gaikwad

## Project Overview

Customized DBMS is a menu-driven Java application designed to simulate basic database management operations. It uses Java's `LinkedList` to store employee records in memory and object serialization to back up and restore data.

The system supports inserting employee records, displaying all records, searching by employee ID or name, deleting records, and saving database backups without requiring an external database.

## Key Features

- Insert new employee records
- Display all employee records
- Search employees by ID or name
- Delete employee records
- Backup and restore data using Java serialization
- Menu-driven console interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework (`LinkedList`)
- File Handling
- Object Serialization and Deserialization

## Storage

Employee records are maintained in memory during execution. Data can be saved to a serialized backup file and restored later.
